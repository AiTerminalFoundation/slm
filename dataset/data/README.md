# Dataset
The dataset is composed by 2 files:
- `all_natural_language.nl` that contains the natural languages prompts.
- `all_commands.cm` that contains all the corresponding bash commands.

The dataset is made in a way that the line `n` in the `all_natural_language` file is the natural language version of the bash command contained in the line `n` of the `all_commands` file.
